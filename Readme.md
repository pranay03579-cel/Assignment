# My Portfolio Website

This is my portfolio website. I made it from a Figma design as part of a frontend assignment. It has a home section, a projects section, a recommendations slider, a contact form and a footer. I also tried to make it work on phones and tablets.

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Fonts (Inter)
- Vercel (to put it online)

## What I Made

- The whole page from the Figma design
- Recommendations section as a slider, with dots at the bottom (the yellow dot shows which slide is showing)
- A menu button for small screens
- A contact form (it does not save anything, it only shows a thank you message)
- Responsive layout using media queries so it does not break on different screen sizes

1. Download or clone this project:
   ```
   git clone https://github.com/YOUR-USERNAME/portfolio.git
   ```
2. Open the folder:
   ```
   cd portfolio
   ```
3. Double click on `index.html` and it will open in your browser.

You don't need to install anything.
